2.3 — Original Addition (State)

Boat travel mode. A fourth concrete state, Boat, extending the State pattern used for movement. A traveller can only board it from OnFoot while at a water location, and can only return to OnFoot by disembarking at a shore — both guarded transitions implemented entirely inside Boat's and OnFoot's own getNextMode() overrides.

This required no changes to Traveller or TravelMode at all: Traveller only ever holds a TravelMode* and calls the same two virtual methods regardless of which concrete mode is active, so a new mode is invisible to it by design. This is the direct payoff of letting concrete states drive their own transitions
